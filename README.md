🔍 Project Overview

This project presents an interactive Tableau dashboard built using the Superstore dataset to analyze key business metrics such as sales performance, profitability, customer segments, and regional trends. The dashboard helps transform raw retail data into actionable insights for data-driven decision-making.

The focus is on identifying sales patterns, profit drivers, and regional performance differences across product categories and customer segments.

📈 Key Insights
Identified overall sales performance trends across multiple categories and regions using interactive visual analysis.
Analyzed profitability patterns, highlighting high-performing and low-performing product segments.
Evaluated regional sales distribution, uncovering strong and weak markets for business expansion.
Studied customer segment behavior, helping understand contribution to overall revenue and profit.

📊 Dashboard Features
KPI overview (Sales, Profit, Quantity, etc.)
Regional performance analysis
Category and sub-category breakdown
Time-series sales and profit trends
Interactive filters for dynamic exploration
🛠️ Tools & Technologies

Tableau, Data Visualization, Business Intelligence, Superstore Dataset, Data Analysis
